Política de privacidade – SM Escrita Planilhas

Quem é o responsável. Santana Melo Advogados, Av. João Durval Carneiro, 3803, sala 1206, Feira de Santana/BA.

O que o aplicativo acessa. Somente o escopo do Google Sheets (spreadsheets), para ler e gravar as planilhas de trabalho do próprio escritório. Não acessa e-mail, Drive, contatos nem qualquer outro dado da conta Google.

Para que usa. Exclusivamente para manter as planilhas internas de controle do escritório atualizadas. Os dados não são vendidos, compartilhados com terceiros, usados para publicidade nem para treinar modelos de inteligência artificial.

Onde ficam. As credenciais ficam apenas nos computadores do escritório. O aplicativo não mantém servidor próprio nem banco de dados externo.

Revogação. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso das informações recebidas das APIs do Google segue a Google API Services User Data Policy, inclusive os requisitos de uso limitado.
